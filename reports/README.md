# Происхождение результатов

Числа отчётов в этой папке относятся к приложенному архиву: 383 звонка, precision 0.6736, recall 0.4363, temporal 0.3260, state 0.4575 после tariff-catalog-v1.

Командная презентация описывает также downstream-результат с precision 0.5366 и recall 0.5122. Соответствующий metrics_report.json в переданном комплекте отсутствует, поэтому эти числа не подменяют показатели архивного checkpoint. Это разные наборы свидетельств, не утверждение об ошибочности командной доработки.

Три GPU-точки: четыре диагностических звонка, один проход на T4, с учётом тайм-аутов и ошибок. CPU float32 измерен отдельно, лимиты 600/120 с различаются. Ускорение относительно официального большого baseline не доказано. Строгий усиленный adversarial-бенчмарк отсутствует. Temporal/state-пороги не достигнуты в опубликованном архивном прогоне.
